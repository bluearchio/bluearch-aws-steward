# Code Of Conduct

This project follows the [Contributor Covenant Code of Conduct, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Project participants must provide a respectful, harassment-free environment.
Report conduct concerns privately to `support@bluearch.io`. Maintainers will
review reports confidentially and may remove content or restrict participation
when needed to protect the community.
